Automatización: Revisión y Firma de Informes de Supervisión

El Problema
En la gestión administrativa pública, la validación manual de informes de supervisión y cuentas para firma digital suele ser un proceso lento y propenso a errores humanos de digitación.

Mi Solución: Proyecto Revisión de cuentas.
Desarrollé una herramienta integral que automatiza este flujo conectando dos tecnologías clave:

VBA (Excel): Gestiona la interfaz de usuario y la base de datos de los contratos por procesar.

Python: Realiza la lectura avanzada de los archivos PDF para extraer datos precisos y validar firmas.

Impacto y Resultados
Eficiencia: Reducción drástica del tiempo de revisión por documento mediante la automatización de validaciones.

Seguridad: Verificación automática de campos obligatorios antes de proceder a la firma digital.

Optimización: Transformación de un flujo de trabajo manual pesado en un proceso digital fluido y confiable.

Dato Técnico: La integración permite que el sistema "entienda" el contenido de los informes PDF y los cruce con la base de datos local en tiempo real.

Perfil Profesional: Tecnólogo en Gestión de Redes & Estudiante de Ingeniería Telecomunicaciones (UNAD).
